A utility which expands the standard Linux terminals features

~~~
Parzii@htb[/htb]$ sudo apt install tmux -y
~~~

-y flag automatically answers yes to installation prompts

start tmux using "tmux"


CTRL + B is the prefix which indicates we want to use a TMUX command

New window: C

Change window: 0 or 1 etc

Split vertically: SHIFT + %

Horizontally: SHIFT + "

When split, the arrow keys can be used to move between panes
