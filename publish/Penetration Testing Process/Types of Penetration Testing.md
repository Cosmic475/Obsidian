

| Blackbox | Very minimal information is provided by the customer - perhaps a couple of IP addresses and a domain                                |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Greybox  | Intermediate levels of information, such as hostnames, subnets or URL's                                                             |
| Whitebox | Detailed information provided by the customer, such as network topology, credentials, web application source code or configurations |
- Naturally, less information complicates the penetration test and will take more time + money. 
	- Amplified if the customer wants a stealthier operation
