SSH runs on port 22 by default and allows us to securely access a remote host. SSH can be configured to use either a password or public-key authentication

It is a TCP connection, and is often used to enumerate, establish persistence or execute other tools on the target network.

~~~
ssh Callum@10.10.10.10

Callum@remotehost's password: ******

Callum@remotehost#
~~~
